Fonts used by the website, both under the SIL Open Font License 1.1, cut down for the web: only the
Latin characters the site uses are kept, converted to WOFF2.

- Kazesawa (https://github.com/kazesawa/kazesawa), release alpha-v1, by polamjag: M+ FONTS with
  Source Sans Pro. Body text and song titles. Weights: Regular 400, Semibold 600, Bold 700,
  Extrabold 800. License: LICENSE-Kazesawa.txt.
- Exo (https://github.com/NDISCOVER/Exo-1.0, from github.com/google/fonts): headings, labels, and
  numbers. One variable file covering weights 100 to 900. License: LICENSE-Exo.txt.
